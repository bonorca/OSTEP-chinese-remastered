# 操作系统导论(Operating Systems: Three Easy Pieces / OSTEP)中文翻译重制版


有劳各大国企出版社让我第4次觉得中文比英文难懂，前几次是伟大的机械工业出版社，其对原版一字一句都对应的、牢牢抓住英文语法精髓的翻译让我看的啧啧称奇。看到内容精彩绝伦的原版被翻译的狗屁不通实在可惜，于是决定由ai翻译，自己校对，目前看来质量显然比官方那个百度一键翻译质量高不少, 至少你不会再看到时间状语从句横行了，例如：

```
# 原版
编译器完成剩下的事情，确保在你进入 func() 函数的时候，在栈上开辟空间。

# 重制版
剩下的事由编译器完成：你调用 func() 时，它会确保在栈上腾出空间
```

```
# 原版
为了确保操作系统这样做，我们需要一些目标来指导。

# 重制版
为了确保操作系统做到这一点，我们需要一些目标来指引方向
```

```
# 原版
让问题更明确一点。管理空闲空间当然可以很容易，我们会在讨论分页概念时看到。如果需要管理的空间被划分为固定大小的单元，就很容易。在这种情况下，只需要维护这些大小固定的单元的列表，如果有请求，就返回列表中的第一项。

# 重制版
我们把问题说得更具体一些。管理空闲空间当然可以很容易，我们在讨论分页（paging）概念时就会看到。如果你管理的空间被划分成固定大小的单元，事情就很简单：只要用一个列表记下这些固定大小的单元；客户端请求一个单元时，返回列表的第一项即可。
```
以上只是一些小小的中文震撼，其实整本书都可以这么对比，我不知道作者的中文语法学自哪个星球，至少并非是我熟知的。
